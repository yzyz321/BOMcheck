BOM 对比工具 V4.2.0
===================

支持 Windows 10 / 11（64 位）。单个 exe，免安装、免 Python、免运行库，
拷到哪台机器都能直接双击。

怎么启动
--------
双击 BOMCheck_V4.2.0.exe（图标是蓝紫渐变 + 放大镜，任务栏和标题栏都能认出来）。
  - 只有这一个文件，没有 _internal 之类的伴随目录，可以单独拷到桌面。
  - 不要直接在压缩包里双击运行，先解压。
  - 想放桌面就建个快捷方式，或直接把 exe 拷过去。

用法
----
1. 把旧 BOM 拖到左边卡片，新 BOM 拖到右边卡片（也可点「浏览…」选）。
   两份一起拖也行，按资源管理器的显示顺序分成「旧 / 新」。
2. 两张卡片各选一个工作表：默认自动挑「数据行最多」的那张，封面 / 修订记录页
   不会顶替真正的 BOM 表。
   两侧都是多页工作簿时，程序自动进入逐表比对（按钮显示「逐表比对」），
   按「同名表」一张一张比：差异结果一表一份（名字带表名，例如
   …_Main_差异结果.xlsx），标注合并成一份（所有比过的页都涂好色，文件名不带表名）。
   两侧都没有数据行的页会跳过，运行日志里逐表写明「差异 N 行 · 已并入标注」
   或「跳过：两侧都没有数据行」。
   只想比其中一张：在工作表下拉里选具体表名即可（按钮会变回「开始比对」）；
   下拉第一项「全部工作表（逐表比对）」可以再切回全比。
3. 点「开始比对」。配对是全自动的四步：料号直配 → 位号兜底 → 位号近似 →
   剩下的按新增 / 删除处理。
4. 结果表 12 列，颜色含义见表格下方那一行图例：
     新增行绿、删除行红、变更行黄；重复料号只把料号格涂浅紫。
   首列 Part Number 冻结：拖底部横向滚动条只滚其余 11 列。
5. 写出 3 个文件，位置：旧 BOM 所在目录下的 checkresults\
     <旧主名>_vs_<新主名>_差异结果.xlsx     差异清单（第 2 页为「识别诊断」）
     <旧主名>_差异标注_旧.xlsx              旧文件副本：删除行红、变更格黄
     <新主名>_差异标注_新.xlsx              新文件副本：新增行绿、变更格黄
   若该目录不可写（只读盘、无权限、U 盘写保护），程序会弹窗让你另选目录；
   取消则本次不写文件，界面上的结果仍可查看。
   逐表比对时：差异结果按表各一份（…_<表名>_差异结果.xlsx），旧 / 新标注仍各
   一份，里面把每一张比过的表都涂好色（文件名不带表名）。
   想换地方重写：点「另存结果…」再选目录。源文件永不改动（只读打开、不改一个字节）。
6. 「运行日志」页签按时间顺序记：载入哪份文件 / 哪个工作表 / 多少数据行 /
   料号列 / 配对统计 / 三份文件的落点。出问题报这一页的原文即可。

比对选项（能改的三项）
----------------------
卡片下方「③ 比对选项」里，前两项固定按推荐值走（顺序配对、整行任一格），
后三项可以改，改完立刻重算，日志里会记一行「比对选项：…」：

  双键（位号兜底）  默认关。料号对不上的行再拿位号认一遍：同一颗料换了料号、
                    或旧表这行料号空着而新表补上了，都靠它配成一对。关着时
                    「没有料号」的行整行跳过（日志会写跳过了多少行），不会硬
                    凑成「新增 + 删除」两条。
  近似阈值          只在双键开着时有效，默认 0.90。点数字框换下一档
                    （0.40 → 0.50 → … → 0.95 → 回到 0.40），鼠标滚轮在框上
                    ±0.05 微调。两行位号集合的重合度（相同个数 ÷ 合起来的不
                    重复个数）≥ 阈值才算同一颗料。0.90 几乎要求位号完全一致；
                    调到 0.60 会把「差一两个位号」的行也算成同一颗料。
  整行逐列比较      默认关。勾上后除料号 / 位号 / 数量 / 删除线以外的列
                    （描述、规格、厂商…）也逐格比，任一格不同即算「变更」，
                    变更项写「其他列」，并把不一样的那几格涂黄。

调高阈值 = 配上的更少、新增/删除更多；调低反过来。默认值对常规 BOM 够用，
除非结果里出现「明显两颗不同的料被按位号配成一对」，再往上调一档。

标题栏版本号旁边的「使用手册」按钮打开随包的用户使用手册.html；那份文件不在时，
会弹一段简要说明：双键、近似阈值、整行逐列比较，以及「新旧选同一个文件 = 料号查重」。
手册在、但系统打不开时，提示框会给出错误码和三种常见成因（受保护目录 / .html 关联
损坏 / 安全软件拦截），不会点了没反应。

查重（同一个文件）
------------------
如果两侧选的是同一个文件（同一个文件比差异没有意义），主按钮会自动变成
「开始查重」，按 Part Number 数重复行：

1. 结果表换成 8 列：Part Number / 重复次数 / 查重结果 / 位号 / 数量 /
   删除线 / 行号 / 工作表；重复行整行浅紫，图例同步换成单色版。
2. 统计在右上角与状态栏：多少行重复、涉及多少个料号。
3. 自动写出 1 个文件，位置同上（源文件目录下的 checkresults\）：
     <主名>_查重标注.xlsx   源文件副本：重复行整行浅紫，料号格带批注
                            「料号重复 n/N（本页共 N 处）」
4. 口径：同一料号出现 2 行及以上即为重复；没有料号的行不参与判重（会单独
   计数说明）。没有发现重复时不生成文件，状态栏会直接说。
5. 换回两个不同文件，按钮与 12 列结果、四色图例都会自动恢复。

标注文件保留什么
----------------
标注不是「重新画一张表」，而是在原 xlsx 包内改单元格样式和批注，其余部件按
压缩字节原样搬走。所以列宽、行高、字体、边框、合并单元格、条件格式、图表、
图片、数据透视表、VBA 宏都原样保留。

被改的只有两处：目标工作表的 sheetN.xml（样式索引）和 styles.xml（新增填充色）。
源文件上的批注也一条不动；如果原表已经有批注，程序会整体跳过批注写入，只在
状态栏提示一句，底色照常涂。

首次运行可能被 SmartScreen 拦
-----------------------------
弹窗「Windows 已保护你的电脑」不是报毒，而是因为这个 exe 没有代码签名、
且是本机新生成的程序，Windows 不认识它。三种处理方式，任选其一：

1) 单文件解除锁定（推荐）
   右键 exe → 属性 → 勾选「解除锁定」→ 确定；或在 PowerShell 里：
   Unblock-File .\BOMCheck_V4.2.0.exe
2) 整包分发
   发 zip 时让接收方先右键 zip → 属性 → 解除锁定，再解压，里面的文件就不拦了。
3) 长期方案
   用企业代码签名证书签 exe（内网分发最省事）；或放到域内共享目录运行，
   从共享目录启动一般不带「来自 Internet」标记。

注意：程序本身不联网、不写注册表，只在旧 BOM 目录下写 checkresults。

自检
----
不确定 exe 是否完好、DPI 声明对不对，可以命令行跑：

    BOMCheck_V4.2.0.exe --self-check     资源、manifest、DPI 声明逐项打勾
    BOMCheck_V4.2.0.exe --version        版本号 + 编译时间

V4.2.0 修了什么
--------------
本版是一次全量代码审查后的修复版，用户能感觉到的变化有这么几条：

  - 某些格式异常的 xlsx 会让程序一打开就闪退，现在会跳过那几行、正常打开。
  - 另一些异常文件会把程序卡死不动（任务管理器才能结束），已修。
  - 料号写在合并单元格里时，以前只认合并区的第一行，现在整块都算，
    纵向合并的 3 行会全部建档参与比对。
  - 查重模式下点「另存结果…」以前必定失败，现在能正常写出查重标注。
  - 表格超过 65535 行时，竖向滚动条以前拖不到底，现在正常。
  - 单元格文字里的 & 符号以前会被吞掉（显示成少一个字符），已修。
  - 日志里「数据行」与「建档行」以前是同一个数，现在分开统计；
    「数据行」是这一页的行数，「建档行」是真正参与比对的物料行。
  - 逐表比对中途失败不再留下半成品文件。

说明
----
- 本版为 C/C++ 重写版，单个 exe 约 690 KB（`tools/check_exe.py` 会报准确体积），
  静态链接，零第三方运行库依赖。
- 界面按 PerMonitorV2 声明，150% / 200% 缩放下不糊、不错位。
- Python 原型（V3.2.0）保留在源码仓库里只作对账 oracle，不参与打包，
  目标机也不需要 Python。
- 写出的 xlsx 自己实现 deflate 压缩（不依赖 zlib），体积与 openpyxl 写出的
  基本持平；压缩没有变小时自动退回不压缩。

性能参考（同一台机器，10 万行 x 2 份）
-------------------------------------
  读取 + 识别 + 配对 + 写出差异表      约 0.65 秒
  再算上标注新旧两份表（共出 3 个文件）  约 2.4 秒
  5 千行的常规 BOM                    0.1 秒以内
  10 万行的差异结果表约 380 KB（内部按 deflate 压缩，和 Excel 自己存的
  文件一个量级；不压缩的话同样内容要 3.5 MB）。
