改法一（推荐，即时生效）　点图下方的「编辑」，直接改 JSON：nodes 是方框、edges 是连线、texts 是自由文字，改完点「应用修改」，改动会存在本机浏览器里。
改法二（改文件）　用文本编辑器打开本 HTML，搜索 const DIAGRAMS，八张图的数据都在那一个数组里；页面首次打开即按它渲染。
常用字段　x / y / w / h 定位与尺寸，label 主文字（模块或动作名），sub 副文字（涉及文件名），theme 取 blue / amber / gray；edges.d 直接写 SVG 路径，如 M340 84 L340 110。
导出　「导出 SVG」可得到矢量图，直接拖进 Word / PPT / Visio 不失真。
全部图形由页面内的数据实时生成，无外部依赖，可离线打开。
