# GUI 控件位置对照表（V4.2.0）

> 本文件由 `BOMCheck_V4.2.0.exe --export-layout-doc <路径>` 直接导出，坐标取自程序正在使用的布局表，不是手抄。
> 改动界面后重新导出即可，不会出现「文档与程序对不上」。

- 基准客户区：**1080 × 720** 逻辑像素（96 DPI 下的 1:1 尺寸）
- 最小窗口：980 × 620；再小就按最小值夹住
- 拉伸规则：坐标 = 基准 + (当前尺寸 − 基准) × 拉伸系数；系数为 0 表示钉死在左侧/顶部
- 本文档的「100%」列按当前显示器 DPI 换算出的物理像素给出
- 合计 **49** 个控件
